- Desenvolvo aplicações web completas, do banco de dados à interface, com APIs REST autenticadas e código organizado em camadas.
- Atuo de forma autônoma como desenvolvedor desde 2024 e presto suporte técnico de TI desde 2019.
- Entreguei em produção um sistema para oficina mecânica com atendimento automatizado via WhatsApp e gestão de ordens de serviço.
